# Happy Birthday Hareem 🎈✨

An interactive and responsive birthday website built from scratch to celebrate Hareem's special day.

---

## 📌 Project Overview
A custom-built single-page web application designed to create an engaging birthday greeting experience using modern web styling, smooth CSS animations, and interactive JavaScript elements.

## 🚀 Technologies Used
* **HTML5:** For semantic markup and structured layout
* **CSS3:** For custom styling, animations, and responsive layout design
* **JavaScript (ES6):** For dynamic user interactions, click events, and functionality

## ✨ Key Features
* **Responsive Layout:** Optimized to fit cleanly across different laptop and desktop screen sizes
* **Interactive Elements:** Engaging user triggers and dynamic features powered by JavaScript
* **Custom Styling:** Clean, modern visual presentation with smooth CSS transitions
* **Lightweight & Fast:** Built entirely using core web technologies without external frameworks
